# Adobe Acrobat Pro PDF Editor

> Edit PDF content, organize pages, convert documents, complete forms, and manage signatures in one document workspace.

Adobe Acrobat Pro is PDF software designed for creating, editing, reviewing, converting, and managing digital documents. It provides tools for modifying text and images, rearranging pages, combining files, completing forms, and preparing documents for sharing.

The application supports document workflows that involve editing existing PDFs, converting files between formats, collecting signatures, reviewing changes, and applying protection to sensitive information.

Acrobat provides tools for modifying PDF content and adjusting document structure without rebuilding the entire file from its original source.

| Capability | Description |
|---|---|
| Text editing | Correct text, adjust formatting, and modify supported PDF content |
| Image editing | Add, move, resize, or replace supported images |
| Page organization | Insert, delete, rotate, and reorder pages |
| Document merging | Combine multiple files into a single PDF |
| PDF splitting | Separate selected pages into individual documents |
| File conversion | Export PDF content to supported document and image formats |
| Document protection | Apply supported security settings to sensitive files |
| Document review | Add comments and annotations during review |

Editing availability can depend on document permissions, file structure, and whether the PDF contains restricted or signed content.

## Document Protection and Review

Protection and review tools help manage access to sensitive files and collect feedback during document preparation.

| Tool | Purpose |
|---|---|
| Password protection | Restrict access to supported documents |
| Permission settings | Control certain editing, copying, or printing actions |
| Redaction | Permanently remove selected sensitive content using supported redaction tools |
| Comments | Add feedback and review notes |
| Annotations | Mark document areas that need attention |
